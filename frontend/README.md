# Витрина автообъявлений

Фронтенд поверх [Car Ads API](../README.md) — REST-сервиса на PHP 8 и Yii2.

**Стек:** Next.js 16 (App Router), React 19, TypeScript, CSS Modules.

## Устройство

```
Браузер ──▶ Next.js (сервер) ──▶ Car Ads API (PHP 8 / Yii2) ──▶ PostgreSQL
```

Браузер к API **не обращается напрямую**: список и карточка — серверные
компоненты, форма отправляется через Server Action. Отсюда три следствия,
ради которых так и сделано:

- CORS настраивать не нужно вовсе — кросс-доменных запросов из браузера нет;
- адрес и внутреннее устройство API не попадают в клиентский бандл;
- в кластере обращение идёт к Service внутри namespace, не выходя наружу
  через ingress и TLS.

Модуль `lib/api.ts` помечен `server-only`: если он случайно попадёт в
клиентский компонент, сборка упадёт, а не утечёт.

| Маршрут | Что делает | Режим |
|---------|-----------|-------|
| `/` | список с пагинацией через `?page` | динамический |
| `/cars/[id]` | карточка объявления, 404 через `notFound()` | динамический |
| `/cars/new` | форма размещения | статический + Server Action |

## Валидация живёт на сервере

Правила проверки полей **не продублированы** во фронтенде. Единственный их
источник — бэкенд, который выводит границы из описания схемы БД
(`src/Schema/CarSchema.php`). Форма лишь раскладывает присланную карту
`поле → сообщение` из ответа `422` обратно по своим полям, включая вложенные
ключи вида `options.year`.

Практический смысл: новое правило на сервере появляется в интерфейсе само,
без единой правки здесь. Атрибут `required` в разметке оставлен только для
мгновенной подсказки браузера на пустом поле — авторитет за сервером.

## Запуск

```bash
npm install
cp .env.example .env.local     # при необходимости поправить адрес API
npm run dev                    # http://localhost:3000
```

Сборка и проверки:

```bash
npm run build
npm run lint
npx tsc --noEmit
```

## Решения, которые стоит пояснить

- **Без UI-кита.** CSS Modules и токены в `app/globals.css`. Тема учитывает
  три состояния: явный выбор, системную настройку и её отсутствие — полная
  светлая палитра объявлена на голом `:root`, тёмная переопределяет только
  токены.
- **Без `next/image`.** Домены фотографий задаёт пользователь, заранее их
  список неизвестен, а `next/image` требует перечислить разрешённые хосты.
  Вместо этого `components/CarPhoto.tsx` подставляет заглушку по `onError`:
  на доске объявлений мёртвая ссылка на фото — обычное дело, и выглядеть она
  должна как отсутствие фотографии, а не как поломка сайта.
- **Пагинация ссылками, а не состоянием.** Страница живёт в URL, поэтому её
  можно скопировать, открыть в новой вкладке и вернуться кнопкой браузера.
  Клиентский JS для этого не нужен.
- **Состояние формы вынесено в `form-state.ts`.** Модуль с `'use server'`
  может экспортировать только асинхронные функции; константа начального
  состояния рядом с экшеном превращалась на клиенте в `undefined`.
